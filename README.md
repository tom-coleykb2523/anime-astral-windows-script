## About the Utility

Anime Astral Script Engine is a standalone utility for Windows 10 and Windows 11, designed for use with Anime Astral Simulator on Roblox. It brings together cooldown-based summoning automation, ordered farming through chosen zones, and tools for observing an active session.

During a run, the utility can log rare drops together with timestamps and apply selected pet or aura loadouts. Session duration, drop limits, pause and resume behavior, release information, and live statistics can all be configured or reviewed as needed.

---

## Capabilities

- Repeat summoning actions using the configured cooldown.
- Farm selected areas in the order defined by a zone queue.
- Save rare-drop entries with their associated timestamps.
- Automatically use chosen pet and aura loadouts.
- Suspend or continue activity with a user-selected hotkey.
- Monitor the current session through live status information.
- Configure maximum session time and drop-count thresholds.
- Check the application version and release notes from within the utility.
- Run the standalone build without installing a separate package.

## Configuration Reference

The following controls are available before a session begins:

| Setting | Purpose |
|---|---|
| Summoning cooldown | Determines the interval between repeated summoning actions. |
| Farming zone queue | Specifies the sequence used to process farming zones. |
| Pet loadout | Chooses the pet setup used during the session. |
| Aura loadout | Chooses the aura setup used during the session. |
| Pause/resume hotkey | Defines the key that pauses or continues activity. |
| Session time limit | Stops the active run once the selected duration has elapsed. |
| Drop-count limit | Ends the session after the configured number of drops is reached. |
| Session monitor | Presents live status, elapsed session time, and tracked drop information. |
